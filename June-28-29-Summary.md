# Summary of Changes: June 28th & 29th

This document outlines the major feature additions and user experience enhancements implemented on June 28th and 29th.

## Article Reader Enhancements

### 1. Highlight Management System
A comprehensive system for managing text highlights has been added to the article reader.

- **Highlights Sidebar**: A new sidebar now appears on the right side of the article reader. It lists all highlights made by the user on the current article, providing a quick overview of their notes.
- **Highlight Deletion**: Users can now delete highlights. A "delete" button appears next to each entry in the highlights sidebar, allowing for easy removal of unwanted highlights from both the article text and the database.

## Digital Library Updates

### 2. Dual PDF Reading Options
The Digital Library has been updated to provide more flexible reading options for core texts.

- **Integrated PDF Viewer**: The primary "Read Now" button now opens books directly within the application using a custom, embedded PDF viewer (`BookReaderPage`). This provides a seamless, integrated reading experience without leaving the platform.
- **External PDF Viewer**: A new "Open Externally" button (with an external link icon) has been added. This button opens the PDF in a new browser tab, utilizing the browser's native PDF viewing capabilities. This is ideal for users who prefer their browser's reader or want to use browser extensions.

These changes significantly improve the interactivity of the article reader and the functionality of the digital library, offering a more robust and user-friendly experience.
